   Find the head of each git source's upstream, from `config.yaml`: for each source whose `type` is `git`, in its order, CALL `shell__run` with the command `git ls-remote <repo_url> refs/heads/<branch>`, `<branch>` being the source's `branch`, or `main` when it has none. If its exit code is 0 and it printed a line, the source's observation is `{"id": <id>, "head": <the first field of the line, the commit>}`. Otherwise it is `{"id": <id>, "error": "git ls-remote <repo_url> refs/heads/<branch> failed: <what it printed>"}`. A source that is not `git` has no observation. The list of the observations, in the order of `config.yaml`, is `observed`.
