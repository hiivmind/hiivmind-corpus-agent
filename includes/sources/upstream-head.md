   Find the head of each git source's upstream, from `config.yaml`: for each source whose `type` is `git`, in its order, CALL `shell__run` with the command `git ls-remote <repo_url> refs/heads/<branch>`, `<branch>` being the source's `branch`, or `main` when it has none. The head is read from STDOUT only, never from stderr. If its exit code is 0 and STDOUT holds a line ending `refs/heads/<branch>`, the source's observation is `{"id": <id>, "head": <the first field of that line, the commit>}`. If its exit code is 0 and STDOUT is empty, the observation is `{"id": <id>, "error": "git ls-remote <repo_url> refs/heads/<branch> failed: no such branch"}`, or with the text stderr printed in place of `no such branch` when it printed any. If its exit code is not 0, the observation is `{"id": <id>, "error": "git ls-remote <repo_url> refs/heads/<branch> failed: <what it printed>"}`. A source that is not `git` has no observation. The list of the observations, in the order of `config.yaml`, is `observed`.
